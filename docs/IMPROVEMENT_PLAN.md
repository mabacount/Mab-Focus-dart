# Mab-Focus-dart — Codebase Inspection & Improvement Plan

- **Repository:** `E:\Develop\Mab-Focus-dart` (branch `focus_v4_update`)
- **Baseline Version:** `4.0.0+1` → **Target Release:** `4.1.0+2` (M5)
- **Inspection Scope:** Line-by-line audit of `lib/` (core, models, providers, services, dashboard/widget/shared UI), `windows/runner/` (Win32 C++ host), `pubspec.yaml`, and `test/`.

---

## Priority & Status Legend

### Priority Levels
- **P0 (Critical):** Data loss, window lock/freeze, crash-recovery failure, or core user workflow blockage.
- **P1 (High):** Concurrency hazards, leaked listeners/processes, unhandled exceptions, broken navigation/UI occlusion, or major R4–R6 deliverables.
- **P2 (Medium):** Lifecycle edge cases, duplicated helpers, dialog responsiveness/overflows, and secondary UX inconsistencies.
- **P3 (Low):** Long-term modularization, dead-code cleanup, and future schema hardening.

### Implementation Status Values
- `Implemented in M1` — Completed and verified in Milestone M1 (`Core Reliability, Window Lock Fixes & Dashboard Stop Lifecycle`).
- `Planned` — Scheduled for Milestones M2–M5 or post-release backlog.
